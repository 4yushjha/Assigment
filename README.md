# 🛍️ E-Commerce Product Cards

A simple and responsive **E-Commerce Product Cards** website built using **HTML and CSS**. The project displays featured products in a clean card-based layout with product images, names, prices, and Buy Now buttons.

## 🚀 Features

- 📱 Fully responsive design
- 🛍️ 10 featured product cards
- 🖼️ Product images
- 💰 Product prices in Indian Rupees (₹)
- 🖱️ Hover effects on product cards
- 🔘 Interactive Buy Now buttons
- 📊 Responsive CSS Grid layout
- 💻 Works on desktop, tablet, and mobile devices

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **CSS Grid**
- **Responsive Design**
